- Solo se **agregan** filas. Una decisión reemplazada no se borra: se marca "Reemplazada por Dxx" y se agrega la nueva.

| D24 | Fusiona PRs a `main` quien dio la aprobación o cualquier otro developer; el autor nunca fusiona su propio PR. Lo ideal es que fusione el Revisor 2 al aprobar ([quién es](proceso.md#glosario)). Si el PR agrega variables a la API, no se fusiona hasta que el PO confirme que cargó el secreto en Cloudflare ([despliegue.md](despliegue.md#ambiente-desplegado)). GitHub borra la rama remota al fusionar si está activado "Automatically delete head branches"; si no, quien fusiona le da "Delete branch". La copia local no se borra sola: cada quien la elimina con `git branch -d <rama>`; con Squash and merge Git suele responder "not fully merged" aunque el PR ya esté fusionado, y entonces se usa `git branch -D <rama>` solo después de confirmar en GitHub que el PR aparece como Merged | El equipo decidió no depender de una sola persona para integrar.
